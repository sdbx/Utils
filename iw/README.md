## Introduction

`iw` is a helper program to make a message like an installation wizard to stdout.

```bash
$ iw --message="TS 암컷타락"
### TS 암컷타락 INSTALL WIZARD ###

The Install Wizard will install TS 암컷타락 in your system.

Press what you would like to:
(1) Install(i) - install TS 암컷타락
(2) Cancel(c) - stop the install

> i

Installing TS 암컷타락...

The Install Wizard has successfully installed TS 암컷타락.

Your system has been modified. To complete installation,
reboot the system at another time.

Enter 'e' to exit the wizard or choose other actions:
(1) Exit(e) - exit the wizard
(2) Reboot(b) - reboot the system to complete the install
(3) Reinstall(r) - make a clean reinstall of TS 암컷타락

> e
```
